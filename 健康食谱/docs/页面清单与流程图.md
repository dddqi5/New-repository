## 三、流程图

### 3.1 首次启动 / 启动流程

```mermaid
flowchart TD
    A[打开 App] --> B[启动页 Splash]
    B --> C{本地有无个人档案?}
    C -- 没有 --> D[首次引导页]
    D --> E{用户选择}
    E -- 保存档案 --> F[写库 + 重算营养目标]
    E -- 以后再说 --> G[进入主框架]
    F --> G
    C -- 有 --> G[进入主框架]
    G --> H{档案是否完整?}
    H -- 不完整 --> I[今日页显示: 请先完善个人档案]
    H -- 完整 --> J[加载今日食谱]
```

**文字版**：打开 App → 启动页判断档案 → 没档案走引导页（可跳过）→ 进主框架 → 档案不完整则今日页给提示，完整则加载食谱。

### 3.2 今日食谱自动刷新流程（核心）

```mermaid
flowchart TD
    A[进入/回到今日页] --> B[读取系统当天日期]
    B --> C{今日食谱缓存是否存在?}
    C -- 存在且日期=今天 --> D[直接展示三张餐卡片]
    C -- 不存在或日期过期 --> E[显示骨架屏]
    E --> F[读取个人档案营养目标]
    F --> G[按 30%/40%/30% 分配三餐热量]
    G --> H[联网检索: 搜索API + 食谱API + DeepSeek]
    H --> I[生成三餐食谱]
    I --> J[写入今日缓存]
    J --> D
    D --> K[点餐卡片 → 餐详情]
    D --> L[点食材 → 食材 Bottom Sheet]
```

**文字版**：读当天日期 → 查缓存 → 有就直接显示，没有就骨架屏 + 联网生成 → 存缓存 → 显示。

### 3.3 个人档案保存流程

```mermaid
flowchart TD
    A[我的页编辑档案] --> B[输入实时校验]
    B --> C{数值合法?}
    C -- 否 --> D[对应输入框标红, 禁止保存]
    C -- 是 --> E[实时显示 BMI/BMR/TDEE/目标热量/三大营养素]
    E --> F[点击保存]
    F --> G[写入本地数据库]
    G --> H[重算营养目标]
    H --> I[清空今日食谱缓存]
    I --> J[用新数据联网重新生成食谱]
    J --> K[首页自动刷新]
```

### 3.4 食材查询流程（点击任意食材）

```mermaid
flowchart TD
    A[点击食材] --> B[弹出 Bottom Sheet]
    B --> C{本地缓存有无该食材?}
    C -- 有且未过期 --> D[展示缓存内容]
    C -- 无/过期 --> E[骨架屏]
    E --> F[联网检索: 营养数据+证据+药物交互]
    F --> G[DeepSeek 整理成结构化结论]
    G --> H[标注来源链接+检索日期+证据等级]
    H --> I[写入缓存]
    I --> D
    D --> J[展示 10 个区块: 名称/优势/营养素/推荐/注意/可能后果/药物交互/证据等级/来源/免责声明]
```

## 五、页面状态约定（每个联网页面都要有）

| 状态 | 表现 |
|---|---|
| 加载中 | 骨架屏（不打转圈遮挡整屏） |
| 成功 | 正常内容 |
| 空数据 | 友好空状态 + 引导按钮（如「去完善档案」） |
| 出错 | 错误提示 + 「重试」按钮，保留上一次缓存内容 |
| 离线 | 展示缓存 + 顶部提示「当前离线，显示上次结果」 |
