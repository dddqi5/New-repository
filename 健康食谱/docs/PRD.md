# 健康食谱 · 一页 PRD（产品需求文档）

> 版本：v0.1 ｜ 阶段：1/8 ｜ 日期：2026-10-02
> 项目地址：`D:\AI应用\健康食谱`

---

## 1. 一句话定位

一款**只给自己用的安卓健康食谱 App**：根据我的个人档案算出每日营养目标，每天自动联网检索并生成早餐/午餐/晚餐食谱，点开任意食材可查看有来源、有证据等级的营养解释。

## 2. 目标用户

- 唯一用户：**本人**（不注册、不登录、不分享）。
- 用户特点：不会编程，手机安装 APK 使用，所有开发/打包在云端完成。

## 3. 核心价值

| 痛点 | 本产品解决方式 |
|---|---|
| 不知道每天该吃多少 | 本地公式算 BMI / BMR / TDEE / 目标热量与三大营养素克数 |
| 不知道今天吃什么 | 每日自动联网检索、按三餐热量比例生成食谱 |
| 网上的营养说法真假难辨 | 所有结论联网检索、标注**来源链接 + 检索日期 + 证据等级** |
| 担心食物/药物冲突 | 药物交互（如葡萄柚与他汀）必须联网查证，只写有来源的结论 |

## 4. 功能范围（首版必须做）

### 4.1 首页 · 今日食谱
- 打开即读取系统当天日期，自动刷新当日食谱，**无需手动刷新**。
- 竖排三张大卡片：**早餐 → 午餐 → 晚餐**（顺序固定）。
- 每张卡片显示：餐名、总热量、蛋白/碳水/脂肪占比、菜品缩略图、菜品名称。
- 点击卡片 → 该餐详情页：食材清单、每道菜做法、营养数据、来源链接。
- 底部导航：**今日 / 搜索 / 记录 / 我的**。

### 4.2 点击食材 · 底部弹窗（Bottom Sheet）
1. 食材名称 + 图片
2. 营养优势（3–5 条，说明"能带来什么"）
3. 关键营养素（每 100g：热量、蛋白质、碳水、脂肪、纤维、钠、钙、铁、维生素等）
4. 推荐搭配（和什么一起吃更好）
5. 注意搭配（分两类：「有科学证据」/「证据不足·民间说法」）
6. 可能后果（**只写有来源的可能影响**，禁止"有毒/中毒/相克"等无来源结论）
7. 药物交互（必须联网查证，如葡萄柚 × 他汀）
8. 证据等级：强 / 中 / 弱 / 民间说法 / 证据不足
9. 来源链接 + 检索日期（可点击跳转）
10. 免责声明（一般信息，不替代医生）

### 4.3 个人档案（页面：我的）
- 字段：年龄、性别、身高、体重、体脂率(可选)、目标体重、目标(减脂/增肌/维持)、活动量、饮食偏好、过敏忌口、疾病用药(可选)。
- 实时校验：年龄 1–120，身高 80–250cm，体重 20–300kg，**超范围标红**。
- 实时显示：BMI、BMR、TDEE、每日目标热量、蛋白/碳水/脂肪克数。
- 点击保存：写入本地数据库 → 重算营养目标 → **清空今日食谱缓存** → 用新数据重新联网检索生成食谱 → 首页自动刷新。
- 首次启动档案为空时引导填写；未填写则首页提示「请先完善个人档案」。
- **档案是唯一数据源**，首页/检索/统计都读这一份，不存副本。

### 4.4 联网搜索规则
- 一切营养知识、食谱、搭配、禁忌必须联网检索，标注来源链接 + 检索日期。
- 权威来源优先：WHO、中国居民膳食指南、NIH、USDA、Harvard、Mayo Clinic、CDC、NHS。
- 不采信无来源、营销号、极端节食、伪科学内容。
- BMR / TDEE / BMI 用**本地公式**计算，不让 AI 凭空猜。
- 三餐热量分配：早餐 30%、午餐 40%、晚餐 30%（可按目标微调）。

## 5. 非功能需求

- 界面干净整洁，**Material 3**；浅色为主，支持深色模式。
- 卡片圆角 16，边距 16，**无广告、无花哨动效**。
- 加载中使用**骨架屏**。
- 数据本地优先（离线可看最近一次结果），联网用于生成/更新。

## 6. 技术栈

- 平台：Android；框架：Flutter。
- 状态管理：Riverpod；本地数据库：Drift / Isar；网络：Dio。
- LLM：DeepSeek API；搜索：Brave / Tavily；食谱数据：Spoonacular / Edamam。
- **不要后端、不要注册登录、不要管理后台、不要上架**。

## 7. 明确不做（Out of Scope）

注册登录、管理后台、支付、社交、广告、上架、医疗诊断。

## 8. 关键假设（开发阶段示例默认值）

年龄 30、男、175cm、70kg、目标维持、活动量轻度、无过敏、中餐。

## 9. 成功标准

- GitHub Actions 能一键产出可安装的 release APK。
- 手机安装后：填档案 → 首页按当日日期自动出现三餐食谱卡片 → 点食材弹出带来源的 Bottom Sheet。
- 所有营养结论均带来源链接与检索日期。
